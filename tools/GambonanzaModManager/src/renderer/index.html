Modpacks

A modpack is a curated bundle of registry mods - one click installs the lot, dependencies included. Packs contain no code of their own: every mod inside comes from the registry, verified exactly as if you installed it alone.

No modpacks yet - be the first! Publish one below.
Publish a modpack

Pick mods from the registry, name the bundle, and submit. Signing in with GitHub opens the registry pull request for you; without sign-in you get a pre-filled submission to post yourself.

Instances

An instance is a named set of mods - like profiles in a Minecraft launcher. The selected instance is what the game loads; switch any time, even from the bar up top. Installs always go into the selected instance.

Publish a mod

Your mod stays in your GitHub repository - the registry only stores a link to it. Players download the file straight from your repo's Releases page, and everyone can read your source. No uploads, no hosting, no accounts to make.
