My modpacks

A modpack is a whole setup: its own mods and its own texture pack, like profiles in a Minecraft launcher. The active one is what the game loads, and anything you install goes into it. Switch any time, even from the bar up top.

Contents
Community modpacks

Setups other people published. Installing one builds it as its own modpack and switches to it, so trying someone else's loadout never disturbs yours. A modpack carries no code: every mod and every texture pack inside is downloaded from its own author's release and checked against the checksum the registry recorded.

Share your setup

One click turns the modpack above into something anyone can install: the mods you have, in the versions you have, plus the texture pack you're wearing. Signing in with GitHub opens the registry pull request for you; without sign-in you get a pre-filled submission to post yourself. Either way it is listed as soon as it's open.

Texture packs

A texture pack re-skins the game: swap any sprite for your own art, reword any line of text. Nothing in your install is rewritten - the framework applies the pack while the game runs, so a Steam update can't wipe it and turning it off is instant. One pack is worn at a time.

Contents
Community packs

Packs other people have published. Each one is a zip of art on its author's own GitHub release - downloaded straight from there, checked against the checksum recorded when it was reviewed, and rebuilt locally before anything is applied. No code, ever: a texture pack cannot contain a mod.

Share a pack

Export your pack, attach the zip to a release in your own GitHub repository, then submit it here. The zip stays yours - the registry only records where it lives and what it hashed to. Signing in opens the pull request for you; without it you get a pre-filled issue to post yourself.

Publish a mod

Your mod stays in your GitHub repository - the registry only stores a link to it. Players download the file straight from your repo's Releases page, and everyone can read your source. No uploads, no hosting, no accounts to make.

Backups

Every time the game is patched, the original game file is copied here first. Restoring a backup puts the game back exactly as it was - you can always just use Steam's "Verify integrity of game files" too.
