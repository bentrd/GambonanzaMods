What it does
Finds your game

Auto-detects the Steam install on macOS, Windows and Linux. Point it at a folder if yours lives somewhere odd.

Patches safely

One click adds mod support. The original game file is backed up first, and "Restore" puts everything back - Steam's file verify works too.

A real mod registry

Browse mods with one-click install and remove. Every mod comes from a public GitHub repo with visible source code and a checksum that's verified on install.

Stays up to date

When Steam updates the game or a new framework ships: notification, changelog, one-click fix. The manager even updates itself - one click and it restarts on the new version.

Creator friendly

Publish a mod by linking your GitHub repo's release - sign in with GitHub and the manager opens the registry pull request for you.

Part of a family

Matches the GambonanzaAssets art editor and the Seed Finder - same look, same "no setup required" attitude.

Getting started
Download & open

Grab the app above. On a Mac, macOS will claim the app is "damaged" - it isn't. That's Apple's blanket warning for free apps that aren't in their $99/year developer program. After dragging the app to Applications, open Terminal (⌘-space, type "terminal"), paste this line and press return - once, and it opens forever:

xattr -cr "/Applications/Gambonanza Mod Manager.app"

Patch the game

The manager finds Gambonanza and one button adds mod support. Takes a few seconds; your original files are backed up automatically.

Pick your mods

Browse the registry, hit Install, and play. Mods load the next time the game starts - toggle them on and off any time.

Questions
Is this safe? It's changing my game files.
The manager makes a backup of the one file it changes before touching it, and "Restore original game files" puts it back byte for byte. Worst case, Steam's Verify integrity of game files re-downloads a clean copy. Mods are downloaded only from their authors' public GitHub repositories and verified against a recorded checksum - if a download doesn't match, it's refused. Mods wearing the reviewed badge had their source code read by a maintainer before being listed; unreviewed ones are fresh community submissions still waiting for that review, and the manager warns you before installing one - read their source first. All of this is open source, so you don't have to take our word for any of it.
macOS says the app is "damaged"?
It isn't - that's what macOS says about any app downloaded from the internet whose author doesn't pay for Apple's $99/year developer program. The fix is one line, once: drag the app into Applications, open Terminal (⌘-space, type "terminal"), paste xattr -cr "/Applications/Gambonanza Mod Manager.app" and press return. The app opens normally from then on. The entire source is public if you'd like to see exactly what you're running.
Do mods break when the game updates?
Steam updates overwrite the patch. The manager notices, tells you, and re-patches with one click - your mods and settings survive. If a game update genuinely breaks the framework, an updated framework release shows up in the manager with a changelog.
Will mods get me banned? Does this touch multiplayer?
Gambonanza is a single-player game and mods only run on your machine. Play fair with leaderboards: some mods (speed, cheats) are clearly labelled - use your judgement.
How do I make a mod?
A Gambonanza mod is a small .NET DLL - the GambonanzaMods repository has the SDK, working sample mods to copy from, and a publishing guide. When it works, publish a GitHub release and submit it from the manager's Publish tab.
Just want to reskin the game's art?
You don't even need this app - GambonanzaAssets is a no-code editor for every sprite in the game.
