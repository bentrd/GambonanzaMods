# GambonanzaMods

A modding framework for the Steam game **Gambonanza**, and the desktop app
that installs it for you.

The patcher adds four call sites to the game's `Assembly-CSharp.dll` and drops
a loader into `Managed/`. After that, a mod is a plain .NET DLL in
`Gambonanza/Mods/<ModName>/`. No Harmony, no MonoMod, no Unity Editor.

**[Wiki](https://github.com/bentrd/GambonanzaMods/wiki)** ·
**[Download the mod manager](https://bentrd.github.io/GambonanzaMods/)** ·
[Changelog](CHANGELOG.md)

## Playing

Download the **[Gambonanza Mod Manager](https://bentrd.github.io/GambonanzaMods/)**
(macOS, Windows, Linux). It finds your game, backs it up, patches it, and
installs mods, modpacks and texture packs from the community registry. It tells
you when anything needs updating and fixes it with one more click. Restore puts
your game back byte for byte.

No terminal, no .NET, no git. Start here:
[Using the Mod Manager](https://github.com/bentrd/GambonanzaMods/wiki/Using-the-Mod-Manager).

## Building

```bash
git clone https://github.com/bentrd/GambonanzaMods.git
cd GambonanzaMods
./build.sh
```

Auto-detects the install, patches it, builds and installs the sample mods.
Re-run it any time - the patcher always works from the `.orig` backup, so it
never compounds.

```bash
./build.sh "/path/to/Gambonanza"   # explicit path if auto-detect fails
./build.sh --skip-samples          # framework only
./sample_mods/build.sh --install   # rebuild samples only (the dev loop)
```

Needs bash (Git Bash / WSL on Windows) and .NET SDK 8.0+. First run copies the
Unity and game DLLs into `refs/` from your own install - they're copyrighted, so
they're never committed.

Then: [Setting Up](https://github.com/bentrd/GambonanzaMods/wiki/Setting-Up) →
[How Modding Works](https://github.com/bentrd/GambonanzaMods/wiki/How-Modding-Works) →
[Your First Mod](https://github.com/bentrd/GambonanzaMods/wiki/Your-First-Mod).

The minimum viable mod:

```csharp
public sealed class HelloMod : Gambonanza.ModSdk.IMod
{
    public void OnLoad(Gambonanza.ModSdk.IModContext ctx)
        => ctx.LogLine("Hello from a mod!");
}
```

...plus a `mod.json` naming that class.

## How it works

Four hooks, and that's the entire footprint. Everything else runs as vanilla.

| Where in `Assembly-CSharp.dll` | Hook |
| --- | --- |
| `Blukulele.Core.GameManager.Start` | `ModHost.LoadAll()` - boot, mod loading, console. |
| `Blukulele.CHE.CanvasMenu.OnEnable` | `ModHost.OnHomeMenuOpenedInvoke(this)` - the CONSOLE button. |
| `Blukulele.CHE.SettingsCanvas.OnEnable` | `ModHost.OnSettingsOpenedInvoke(this)` - fans out to mods. |
| `AchievementManager.UnlockAchievement` / `.IncreaseAchievement` | `ModHost.ShouldBlockAchievement(name)` - pauses Steam achievements while any mod is enabled. |

A marker class `__GambonanzaModHostPatched` keeps the patcher idempotent. The
in-game console opens with `F10` or backtick; type `help`.

Because the framework reaches into private game state by name, a Steam update
is always the first suspect when something breaks. [`GAME_BUILD`](GAME_BUILD)
records the build this checkout was verified against, and `build.sh` warns when
yours differs.

## Publishing a mod

Your mod lives in **your** repo. The registry stores a pointer; players'
managers download straight from your releases. No hosting, and updates ship the
moment you publish a release - there is no upload step, ever.

Open the manager's **Publish** tab, or read
[Publishing Your Mod](https://github.com/bentrd/GambonanzaMods/wiki/Publishing-Your-Mod)
/ [docs/MOD_PUBLISHING.md](docs/MOD_PUBLISHING.md).

## Texture packs

Change how the game looks, without writing anything. The manager's **Texture
packs** tab has every sprite the game ships - all ~200 gambit icons, both piece
sets, every boss, the tiles, the title art - and all 1229 of its strings in 11
languages. Repaint one, drop it back in, wear it. Wear several at once.

Nothing in your install is rewritten: the framework applies the pack while the
game runs, so a Steam update can't wipe it and turning it off is instant. Packs
are zips you can hand to anyone, or publish to the registry.

[Your First Texture Pack](https://github.com/bentrd/GambonanzaMods/wiki/Your-First-Texture-Pack)
· [docs/TEXTURE_PACKS.md](docs/TEXTURE_PACKS.md) · browse the art online at
[GambonanzaAssets](https://bentrd.github.io/GambonanzaAssets/)

## Layout

```
src/ModSdk/       Public API - IMod, IModContext, IModLifecycle, IConsoleApi.
src/ModHost/      Runtime loader, in-game console, texture pack application.
src/GameUI/       Pixel.* helpers for cloning game UI into mods.
src/Patcher/      Cecil-based one-shot patcher.
sample_mods/      GambitApi, custom gambits, overlays. They double as docs.
Mods/             Pre-built drop-ins, if you'd rather not build.
registry/         One JSON pointer per mod. index.json is generated by CI.
tools/GambonanzaModManager/   The desktop app (Electron). See its README.
tools/registry/   Registry validation + index builder.
docs/             UI_API, MOD_PUBLISHING, TEXTURE_PACKS, ASSET_MODDING, RELEASING.
refs/             Hydrated from your own install on first build. Not committed.
prebuilt/         Framework DLLs for release CI, which can't build against the
                  game's copyrighted assemblies itself.
diagnostics/      Throwaway measuring tools. Not shipped.
```
